# Dr. Mona Abdullaeva — premium dental landing page

Mobile-first React + Vite + Tailwind CSS landing page with an interactive before/after gallery, service cards, and a WhatsApp booking form.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Before launch
- Replace the general WhatsApp links with the clinic's verified booking number in international format (digits only).
- Replace portfolio demo imagery with consented, authentic clinical photographs and accurately describe real cases.
- Connect booking to the clinic's CRM/API if direct lead storage is needed. The current form opens WhatsApp with a prefilled request and does not store patient data.
- Add the approved privacy-policy URL and verify medical/advertising wording before publishing.

Vercel settings: build command `npm run build`, output directory `dist`.
